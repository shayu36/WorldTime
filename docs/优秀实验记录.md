从 occupancy 结果看，`epoch_4` 是当前 mIoU 口径最优 checkpoint，`epoch_6` 是 IoU 口径最优 checkpoint。若主指标是 mIoU，优先保留 `epoch_4.pth`；若主指标是 occupied IoU，优先保留 `epoch_6.pth`。

Planning 指标在 `epoch_1` 到 `epoch_12` 中完全一致，说明这轮 Future Adapter 的变化主要体现在 occupancy forecasting，而不是轨迹输出差异。由于缺少 baseline planning 日志，不能声明 planning 相对 baseline 提升。

### C类别组Gate实验：已放弃

C尝试在A+B之上把Semantic Gate按背景、交通参与者、道路设施三个固定类别组细分，
为每个点生成组偏置并展开成17类Gate。其完整评估为：

| C checkpoint | Future IoU | Future mIoU |
| --- | ---: | ---: |
| epoch1 | 22.7900 | 13.1667 |
| epoch2 | 22.7600 | 13.1133 |
| epoch3 | 22.7700 | 13.1400 |

C三轮均未超过A+B epoch1，继续训练也没有上升趋势；固定类别组还把表现方向不同的
类别放在同一Gate中，并且无法直接修复occupancy过滤或位置偏移造成的漏检。
因此C不再作为当前代码路线，其专属代码、配置和运行入口已清除；实验产物仅保留为
历史依据。后续实验以A+B epoch1为起点。
